## Модель данных (ядро)

- `Category` — дерево (parentId), slug, SEO-поля, набор характеристик для фильтров (`CategoryAttribute`).
- `Attribute` — название, тип (число/список/строка), единица.
- `Product` — название, артикул (= короткий код на карточке, напр. `EP-C251`), slug, категория, описание, наличие, фото[], SEO-поля, значения характеристик.
- `Packaging` (фасовка) — товар, объём тары (кг/л/шт), цена за тару. Цена за кг выводится расчётом.
- `ConsumptionRule` (норма расхода) — у товара, см. калькулятор ниже.
- `Kit` (комплект / «система пола») — название, slug, строки `KitItem` (товар + своя норма расхода в этой системе).
- `Order` — контакты, способ получения, комментарий, согласие ПД, позиции (снимок цены), статус (новая / в работе / выполнена / отменена).
- `AdminUser` — до 3, логин + пароль.

## Калькулятор — что видно из «КАЛЬКУЛЯТОРЫ.xlsx»

~30 готовых систем (краски, эпоксид, топпинги/стяжки, Lincrete, Ansaf, Microbeton, химия, самонивелир). Это готовые данные для «Комплектов» и блока «Весь пирог пола».

Типы норм, которые встречаются:
1. `кг/м²` фиксированно (грунт 0,6 кг/м²).
2. `кг/м² на 1 мм` × толщина (Ansaf 2,4; Lincrete SL 1,85; стяжки 2,3–2,5) — это формула из ТЗ.
3. `на погонный метр` (плинтус Lincrete TX — длина вместо площади).
4. `шт на N м²` (армирующий материал — 1 рулон на 100 м²).
5. Фиксированное кол-во на систему, не зависит от площади (ремонтный состав Linolit 11, медная лента).

Округление: всегда вверх до целой тары (`ceil(площадь × норма / вес тары)`).
Закладываю все 5 типов в модель сразу — дёшево сейчас, дорого потом.

Ошибки в исходном Excel (в базе будет единый источник — пропадут сами):
- одна и та же позиция с разными ценами в разных листах (EP-P150: 745 / 808 / 984 / 1000 / 1097 ₽/кг);
- вес тары в формуле кол-ва ≠ вес в формуле кг (Refloor AC-S200: делим на 18, умножаем на 20; Эпоксид F53 делит на 30,6);
- «Самонив.», E6: расход грунта = толщина × 10 вместо кол-во тары × 10.

## Локальный запуск

```
docker compose -f docker-compose.dev.yml up -d
cd web && npm install && npx prisma migrate dev && npm run db:seed && npm run dev
```
Админка: http://localhost:3000/admin — admin / admin (только локальный сид).

## Что сделано

- **Стек:** Next.js 16 (App Router, Turbopack) + PostgreSQL 16 + Prisma 7 (driver adapter `@prisma/adapter-pg`) + Tailwind 4, своя админка. Docker compose.
- **Витрина:** главная-сетка с пагинацией, категории (вложенность, фильтры с наследованием от родителя и подкатегорий, сортировка, пагинация), карточка (фасовки, калькулятор 5 типов норм, «Весь пирог пола» → «Добавить всё»), поиск с подсказками (артикул кириллицей тоже), корзина (localStorage), заявка, **«Проверка технолога»** (кнопка в корзине: телефон + корзина, тип TECH_CHECK), «Спасибо», служебные страницы из админки (markdown), 404, sitemap, robots, OG, JSON-LD, Метрика по номеру из настроек.
- **Админка `/admin`:** заявки (статусы, заметки, тип), товары (фото → WebP sm/md/lg 240/640/1000, фасовки, характеристики по категории, расход, SEO), категории, справочник характеристик, комплекты с предпросмотром расчёта, страницы, настройки (контакты, шаблоны SEO, до 3 админов, кнопка «Проверить уведомления»).
- **Бренд:** логотип векторизован из растра (`web/public/brand/`), акцент `#F4640B`, favicon/apple-icon/og.
- **Данные (сид):** 52 товара и 34 комплекта из Excel Славы (`web/prisma/seed-data/`: parse_xlsx.py → JSON → seed.ts), 21 категория (структура от Славы), 15 характеристик для фильтров, 4 фото, тексты «Контакты» / «Доставка и оплата» (черновик) / «Политика» (адаптирована с polexpert.ru/privacy.html), реальные контакты и реквизиты. - **Проверки:** нагрузка на 1052 товарах (15–80 мс на запрос; ~17 rps под 20 параллельными, p95 1,4 с), Lighthouse мобильный 98–99 / 100 / 100, 360px без горизонтального скролла на 14 страницах, бэкап и восстановление проверены, все server actions админки проверяют сессию, заголовки безопасности.

## Как работать

**Локально** (Windows, Git Bash):
- Docker Desktop на этой машине **не стартует** (WSL `docker-desktop` в состоянии Stopped). Dev-БД — контейнер `betonpoli-devdb` на демо-сервере (127.0.0.1:5434). Поднять туннель (держать в фоне):
  ```
  ssh -o ExitOnForwardFailure=yes -N -L 127.0.0.1:5433:127.0.0.1:5434 skidqi
  ```
  `web/.env` уже указывает на localhost:5433 (betonpoli/betonpoli).
- Затем: `cd web && npm install && npx prisma migrate deploy && npm run db:seed && npm run dev`. Локальная админка: admin / admin (только из локального сида).
- Next 16 dev на Windows не видит новые папки роутов, Tailwind-классы из новых файлов и свежий Prisma-клиент — **перезапускать dev-сервер**.
- `npx tsc --noEmit`, `npx eslint src`, `npm test` — перед каждым деплоем.
- Next 16 — читать `web/node_modules/next/dist/docs/` (async params, `proxy.ts` вместо middleware, `revalidateTag` с профилем).

**Демо-сервер** sqorapro.ru = **5.8.50.152** (ssh-алиас `skidqi`; sqorapro.com — другой сервер, 93.115.14.102, не трогать):
- Код: `/opt/betonpoli-demo/{web,deploy}`, env: `deploy/.env` (BASE_PATH=/demos/betonpoli/live, APP_PORT=3020, DEMO_MODE=1).
- Обновить: залить `web/` и `deploy/` (tar без node_modules / .next / src/generated / uploads / .env, `tar --force-local`), затем
  `cd /opt/betonpoli-demo/deploy && docker compose -p betonpoli-demo --profile tools build && docker compose -p betonpoli-demo up -d`
  (сервис `migrate` применяет миграции до старта app).
- Пересид (стирает каталог и демо-админку): `docker compose -p betonpoli-demo --profile tools run --rm seed`.
- Нагрузочный каталог: `... run --rm seed npx tsx prisma/seed-bulk.ts 1000`, убрать — `--clean`.
- nginx: блок `location ^~ /demos/betonpoli/live` в `/etc/nginx/fastpanel2-sites/sqorapro_ru_usr/sqorapro.ru.includes` (рядом бэкапы `.bak-betonpoli-*`). Страница описания и превью — `/var/www/sqorapro_ru_usr/data/www/sqorapro.ru/demos/` (betonpoli.html, thumbs/betonpoli.webp, запись в demos-data.js); ставить файлы через `install -o sqorapro_ru_usr`.
- На сервере также стоит self-hosted Appwrite (не наш, не трогать).

## Решения и грабли

- **Appwrite не используем**, остаёмся на PostgreSQL (обоснование в чате 02.10: фильтры, поиск, Prisma, лёгкий деплой на прод).
- Демо собирается с `NEXT_PUBLIC_BASE_PATH` (build-time). «Сырые» URL (img, fetch) берут `BASE_PATH` из `src/lib/format.ts`; `metadataBase` — только origin, canonical собирается с BASE_PATH.
- `next.config.ts`: frame-ancestors `'self'` на проде, плюс sqorapro.ru на демо (превью во фрейме на странице студии).
- Prisma CLI в рантайм-образе не работает — миграции и сид идут из стадии `build`.
- `docker build` локально падает с UNABLE_TO_VERIFY_LEAF_SIGNATURE (перехват TLS на машине) — собирать на сервере, strict-ssl не отключать.
- JS `\b` не работает с кириллицей (регулярки в сиде).
- ReactNode-props из server- в client-компонент — давать `key` корневому элементу (иначе warning в React 19 dev).
- Права на `deploy/data/uploads` — uid:gid 100:101 (пользователь app в контейнере); сид пишет фото от него же.
- Тексты для заказчика — от первого лица («я»), plain text в code block (память `client-messages-style`).
